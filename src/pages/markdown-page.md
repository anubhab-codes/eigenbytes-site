# Example Learning Page

This page shows a clean, example-driven explanation of a concept, with a real command, expected output, and why it matters.

## Code example

```bash
cat /etc/os-release
```

Expected result:

```text
NAME="Ubuntu"
VERSION="22.04 LTS (Jammy Jellyfish)"
```

## Why this matters

The command reads the Linux release file and helps you identify the distribution before you install packages or change configuration.
