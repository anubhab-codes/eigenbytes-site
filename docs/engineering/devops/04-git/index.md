Everything in DevOps starts with source control.

Your code, your configuration, your infrastructure definitions, your pipeline files — all of it lives in Git. If you cannot work effectively with Git, you are blocked at the start of every workflow.

This section covers how Git actually works (not just the commands), and how to use it correctly: working locally, branching, collaborating with remote repositories, and the pull request model on GitHub.
