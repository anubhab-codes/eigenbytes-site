# What is Git?

Git is a version control system that tracks changes to files over time.

## Mental model

Imagine a notebook where every change is recorded as a snapshot. You can go back to any snapshot, compare versions, and share changes.

## Example

```bash
git init
```

That creates a local repository that can track your project.

## Result

You can now run:

```bash
git status
```

and see the state of your work.
