Every server you will ever touch runs Linux.

Not Windows Server. Not macOS. Linux.

If you cannot navigate a Linux system, read logs, manage processes, and control access — you cannot operate infrastructure. These are not optional skills.

This section covers the fundamentals that come up every day in real DevOps work: the filesystem layout, the commands you will actually use, how processes and signals work, and how user access is structured on servers.
