# Reference

Two resources for operating real systems.

**Production Architecture** — how the tools in this portal connect in a real production environment. Reference diagrams for a full Kubernetes delivery stack.

**Troubleshooting Playbook** — a diagnostic guide for production failures. Organized by symptom, layered from OS to application. Use this when something breaks and you need to know where to start.
